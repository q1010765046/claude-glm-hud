# GLM-HUD 显示配置

请选择您想要的配置选项：

## 布局模式

请选择布局模式：
- **compact** - 单行模式，所有信息在一行显示
- **expanded** - 多行模式，每项信息单独一行

## 显示选项

请选择要显示的信息：
- **上下文窗口** - 显示当前会话的上下文使用情况
- **Token 使用率** - 显示智谱 API 的 Token 使用配额
- **MCP 使用率** - 显示 MCP 服务器的时间使用率

配置文件位于：`~/.claude/claude-glm-hud.json`
